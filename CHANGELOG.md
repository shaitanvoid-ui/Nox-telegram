# История изменений

Изменения группируются по логически завершённым возможностям. Этот файл описывает код версии, а не заменяет [результаты проверок](docs/qa.md). Production-релиз и публикация GitHub не объявляются без фактического выполнения.

## 2026-10-17 — новая версия Mini App

- Продукт и бот переименованы в Astra; технические идентификаторы конфигурации сохранены.
- Полная замена экранов, компонентов, стилей и навигации по новым визуальным референсам.
- Оригинальная графика из хрома и стекла, чёрно-графитовая палитра, Manrope и Inter, светлые округлые кнопки.
- Новая мобильная оболочка, плавающая навигация, отдельная desktop-композиция и входной экран.
- Рабочие формы модерации, Shield, Studio, аналитики, апелляций и настроек подключены к существующим API.
- Старые styles и сегментированное кольцо удалены; прежний «Контур» остаётся историческим этапом разработки.

## 0.1.0 — начальная версия, в разработке

### Добавлено

- Монорепозиторий Python/FastAPI и React/TypeScript Mini App.
- SQLAlchemy-модели чатов, участников, сессий, дел модерации, аудита, защитных модулей, апелляций, правил, аналитики и входящих updates.
- Alembic и воспроизводимые зависимости; PostgreSQL в Compose, SQLite для локальных тестов и облегчённого demo.
- Серверная проверка Telegram `initData`, срока действия и структуры; непрозрачные сессии, хранение хешей токенов, Redis replay guard и chat-scoped RBAC.
- Общий сервис наказаний с ключами идемпотентности, явными состояниями, причинами и аудитом; ошибки и неизвестные результаты Telegram не считаются успехом.
- Aiogram handlers и интеграционный adapter Telegram, onboarding чата, очередь updates и worker временных наказаний.
- Ограничение одного активного ban/mute на участника и тип; нативный Telegram `until_date` и безопасное обновление локального истечения без отмены более нового ограничения.
- Фоновая очистка Shield/Audit по сроку чата и удаление обработанных payload updates; минимальные receipts сохраняются для дедупликации.
- Shield-фильтры с независимой конфигурацией и журналом сигналов.
- Исполнитель Studio для приветствий, удаления/мута при флуде и мута по порогу предупреждений; приоритеты, проверка прав автора, уникальный ключ события и постоянная история выполнения.
- Mini App с Dashboard и разделами модерации, защиты, аналитики, автоматизации, ручного разбора и настроек; обращения к реальному API локального окружения.
- Изолированный demo-режим с синтетическими данными и mock Telegram adapter; demo-вход запрещён в production.
- Docker Compose, Nginx, пример production HTTPS через Caddy, health/readiness, backup-скрипт и инструменты измерения API.
- GitHub Actions для проверок backend/frontend, E2E и контейнеров; issue и PR templates.
- Русская документация запуска, архитектуры, безопасности, API и эксплуатации.

### Ограничения

Настоящий бот, HTTPS-домен и клиент Telegram подключаются отдельно. AI-provider отключён. Полная функциональность Emergency Mode, всех Shield-модулей, планировщика Studio и Universe не объявляется готовой. Сведения о реально выполненных тестах, внешних ограничениях и нагрузочном запуске находятся в `docs/qa.md`.

Лицензия и удалённое размещение GitHub требуют отдельного подтверждённого состояния; вымышленная ссылка не публикуется.

### Дизайн «Контур»

- Dashboard с фактическим состоянием Shield, сегментированным кольцом и полосой метрик.
- Раздельные дорожки графика, общий выбор дня и таблица данных для скринридеров.
- Диалоги рендерятся вне анимируемых контейнеров и сохраняют фокус при вводе.
