# API NOX

REST API использует префикс `/api/v1`. Источник актуальных схем запросов и ответов — OpenAPI, сгенерированный работающим FastAPI из Pydantic-моделей:

- Swagger UI: `http://localhost:8000/docs`.
- OpenAPI JSON: `http://localhost:8000/openapi.json`.
- [Сохранённая OpenAPI-схема этой версии](openapi.json).
- Схемы клиента и backend следует сверять с `/openapi.json` той же версии сервера.

Страницы документации описывают интерфейс, но не доказывают, что Telegram подключён. Фактические проверки: [qa.md](qa.md).

## Аутентификация

`POST /api/v1/auth/telegram` получает исходные подписанные `initData`. Не передавайте `initDataUnsafe` и не извлекайте пользователя самостоятельно ради выдачи доступа. Успешный ответ содержит короткоживущий `access_token`; далее передавайте его в заголовке:

```http
Authorization: Bearer <session-token>
```

Сессии не передаются в URL. Не сохраняйте токены в истории команд, screenshots, issue или логах. Повторное использование уже обменённых Telegram-данных отклоняется; откройте Mini App заново для нового входа.

Только в `NOX_MODE=demo` доступен `POST /api/v1/auth/demo`. Он создаёт сессию синтетического пользователя для локального стенда. Пример чтения чатов с ранее полученным токеном:

```http
GET /api/v1/chats HTTP/1.1
Host: localhost:8000
Authorization: Bearer <session-token>
```

Любой идентификатор чата из клиента проверяется на сервере. Наличие токена не гарантирует административные права. Ошибка `401` означает необходимость нового входа; `403` — отсутствие разрешения; `429` — превышение ограничений частоты.

## Административные операции

Для наказаний используйте стабильный ключ идемпотентности по схеме в OpenAPI/контракте. Одинаковый логический запрос при повторе должен использовать тот же ключ. Новый случайный ключ при каждом сетевом retry устраняет защиту от дублирования.

Состояние дела проверяйте по серверному ответу. `pending` и `unknown` не равны подтверждённому применению; `failed` не должно отображаться как успех. Общий сетевой timeout также не является доказательством, что Telegram ничего не выполнил.

Для списков соблюдайте поддерживаемые параметры пагинации и ограничения размера страницы. Не предполагается, что все запланированные группы API из master prompt уже реализованы: доступные маршруты определяет актуальный OpenAPI.
