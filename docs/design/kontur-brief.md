# NOX Dashboard — дизайн-спецификация

## 1. Разбор скриншотов (мобильный 390 и desktop 1440)
- **Hero занимает ~320 px на мобильном и ~270 px на desktop** и содержит слоган «Хорошие сообщества начинаются со спокойствия». Он не говорит о состоянии. Иконка-щит с тремя мини-иконками — декор без данных; «8/10» спрятано в плашке 10 px.
- **Заголовок «Всё под контролем.»** — утверждение, которое данные не подтверждают. 80% — доля включённых модулей, а не оценка безопасности.
- **График:** нарушения лежат на шкале 0–2600 и выглядят плоской линией. Подписи оси X на desktop неравномерны и наезжают (10-10, 10-11, 10-12).
- **Мобильная нижняя навигация** нарисована поверх карточек метрик в середине страницы (fixed без отступа контента), перекрывает «Действия модерации».
- **Типографика:** подписи 10–11 px (`Применено`, `Действие`, `Время`, подвал) нечитаемы; контраст muted на surface низкий; метки CAPS с трекингом на каждом блоке.
- **Одинаковые карточки:** 4 метрики + 3 блока с одной рамкой и радиусом → нет иерархии.
- **«На шаг впереди»** — маркетинг (Studio/Intelligence), занимает место рабочей панели; строки со стрелками без различимого действия.
- **Ширина desktop:** контент растянут до 1140 px; таблица действий имеет огромные пустые колонки.

## 2. Концепция: «Контур»
Один узнаваемый элемент — **сегментированное кольцо защиты**. Каждый сегмент = один модуль Shield; закрашен = включён. Всё остальное тихое: без рамок-карточек вокруг метрик (одна полоса с разделителями), один акцент primary, warn используется только для нарушений и действий. Hero = состояние: «Включено 8 из 10 модулей защиты» + одна кнопка.

Отличия: кольцо несёт данные; метрики в одной полосе; график из двух дорожек с разными шкалами; текст-факты вместо слоганов; демо-плашка постоянно видна.

## 4. Композиция
**Mobile (320–767):** колонка. Плашка демо → кольцо 240 (по центру) → заголовок, 1 строка пояснения, кнопка → метрики 2×2 с разделителями → график (на всю ширину) → действия списком из 3 строк → быстрые ссылки 2×2. Отступ снизу `nav-h 64 + safe-area + 32`, нижняя навигация не перекрывает последнее действие.
**768+:** кольцо 200 слева, текст справа в одной строке; метрики 4 в ряд, 48 px; действия — сетка из 5 колонок (аватар, имя, причина, тип+время, статус); быстрые ссылки 4 в ряд. Max-width контента 1120.

```
┌ демо: синтетические данные ──────────────┐
│ ◔ 8/10   Включено 8 из 10 модулей защиты │
│          [Настроить Shield]              │
├ Участники │ Сообщения │ Действия │ 80%  ┤
│ График: сообщения (0–2 600) + нарушения (0–N, своя шкала) │
├ Последние действия ───────── Вся история ┤
└ Модерация │ Апелляции │ Shield │ Studio  ┘
```

## 5. Что заменить
- Старый hero со слоганом, иконкой-щитом и мини-бейджами → `<ShieldRing/>` + заголовок-факт.
- 4 одинаковые карточки → `<dl className="nox-metrics">`.
- `Покрытие защиты` → «Включено модулей» (80% = enabled/total).
- Recharts-график с общей шкалой → `<ActivityChart/>` (два чарта, `syncId`, общий readout, скрытая таблица для скринридеров).
- Блок «На шаг впереди» и «Настройте NOX под ритм» → убрать с Dashboard (маркетинг); Studio остаётся в быстрых ссылках.
- Подвал «Приватность по умолчанию» 10 px → убрать или вынести в Настройки.
- Нижняя навигация: оболочка должна давать `padding-bottom: var(--nav-h) + safe-area` (в CSS уже заложено); сама навигация — `position: fixed; bottom:0; height: var(--nav-h); padding-bottom: var(--safe-b)`, пункты ≥ 44 px, 5 пунктов + «Ещё».

**Подключение данных:** `Dashboard` принимает `status`, `data: DashboardData` и `errorCode` — передайте результат существующего `useQuery` (`status`, `data`, `error?.status`, `refetch`). API и тип данных не менялись. Маршруты `/shield /moderation /appeals /studio` замените на ваши реальные пути. Оси recharts: если у вас Recharts 3, `onMouseMove` читает `activeTooltipIndex` — проверьте тип в вашей версии.

## 6. Критерии приёмки
- На 320, 360, 375, 390, 430, 768, 1440: нет горизонтального скролла, основной текст ≥ 15 px, подписи ≥ 12 px.
- Все тап-цели ≥ 44 px, поля ввода 16 px (без зума iOS).
- Нижняя навигация не перекрывает последний блок; Telegram safe area учтена (`--tg-content-safe-area-inset-top`).
- 8 из 10 → 8 ярких сегментов, 2 тонких; при 0/0 нет NaN и ошибок.
- 3 нарушения в день заметны на графике (своя шкала, подписанная); tooltip/readout одновременно показывает оба значения.
- Контраст текста ≥ 4.5:1; видимый focus; скрытая таблица данных графика.
- Reduced Motion: без анимаций.
- Демо-плашка видна всегда в `mode="demo"`; нигде нет слов «безопасность гарантирована», показателей без источника, кнопок без действия.
- Состояния: загрузка (skeleton), ошибка (повтор), 403 (нет доступа), пустой список действий, пустой график.
